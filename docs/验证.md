# 1.0.1 主控验证

验证日期：2026-11-11。目标与验收依据为同目录唯一草案。

## 本次返工依据

1.0.0 的浏览器测试只覆盖“窗口随键盘缩小”，遗漏了安卓 TauriTavern 2.3 的覆盖式键盘。核对 v2.3.0 官方 Layout 与 MobileStyleAdaptation 文档及输入归属控制器后，确认 IME 偏移注入 active surface，且原插件缺少公开 surface 标记。1.0.1 使用公开 `free-window` 标记并读取 surface-local CSS 变量，同时保留浏览器/宿主联合监听。上游私有实现只用于定位，不复制进插件或发布包。

本次还按反馈改为默认可拖动小窗，并加入实时上下文字符预算与 API token 用量。

## 已通过

- `npm test`：24 项，全部通过。在原有 Agent/资料隔离等覆盖上，新增当前输入/工具说明字符计量、实际 API usage 与不捏造 token、安卓 2.3 本地 IME、宿主快照滞后、不重复扣除、浮窗尺寸、旋转拖动夹取和 VirtualKeyboard 几何。
- `npm run test:mobile`：实际扩展入口加载到 Chromium，宿主/API 为契约形状模拟。完整场景包括搜索及正文工具、来源链接、复制提示词块、模型 HTML 作为文本显示、主故事输入/预设/历史/世界书不变、停止、同故事接续、切换故事后不继承旧补充资料、会话重载及默认不保存密钥。
- 320/390/768 像素宽度无面板和设置表单横向溢出；默认窗高小于屏幕 60%，不显示全屏遮罩，主故事输入仍可操作，标题可拖动、窗口可展开和恢复。
- 宿主停止推送快照、浏览器缩到 390×430 时，输入焦点保留且编辑区与发送按钮可见。
- 安卓 2.3 覆盖式键盘：保持 390×844 视口不变，以 430px 的独立覆盖层模拟遮挡，仅在浮窗注入 IME CSS 变量。输入与发送按钮均处于遮挡线以上，`elementFromPoint` 实际命中对应控件。完全移除键盘几何报告后，上置输入区的退路仍可达。截图 `artifacts/mobile-android-23-ime.png`；浏览器报告 `artifacts/mobile-report.json`。
- 输入内容即时增加字符占用，模拟 API 返回的 prompt/completion token 在界面准确显示，明确与字符及累计费用区分。
- `python tests/installer.py`：只监听回环地址的真实 smart HTTP Git 服务，两次浅克隆成功，manifest 和 js 入口存在，非安装路径拒绝。测试服务已停止。
- 所有运行 JavaScript 模块 `node --check` 通过。
- DeepSeek Chat/Search/Fetch 官方端点跨域 OPTIONS 预检返回 200，允许 Tauri 来源和 Authorization/Content-Type；未使用真实密钥。
