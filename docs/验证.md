# 1.0.2 原生安卓验收

验证日期：2026-11-11。

## 实际环境与原缺陷

本次主要依据是 Android 14 Google APIs 原生模拟器、官方未修改的 TauriTavern 2.3.0 ARM64 APK（通过镜像自带 ARM64 翻译运行）及真实 Gboard，而不是 Chromium 设备尺寸模拟。测试实例与用户手机、既有 AVD 隔离，使用应用自带角色和测试文字，不配置真实模型密钥。

先在原版宿主实际安装已发布的 1.0.1，使用系统触摸点击 Gboard 输入，按 Android 返回键收起键盘。系统显示 IME 已隐藏，textarea 仍持有焦点；旧版因此把布局误切成“未知键盘兜底”，继续隐藏导航并把编辑区放到顶部，无法恢复。实际回归脚本在旧版报出 `Keyboard is closed but navigation remains hidden: focus is not IME visibility`，并保存了原生截图。这不是根据源码推测。

1.0.2 去掉以焦点推测键盘、重排编辑区的分支，依据实际宿主/浏览器/IME 几何夹取位置；用无键盘视口维持小窗基准尺寸。原本不被挡住的窗口不动，需要避让时才移动/缩小，收起后恢复，即使编辑器仍有焦点。

## 真实安卓结果

通过原应用实际的扩展安装/更新接口升级到 1.0.2，并确认实际载入的版本后完成：

| 真实软键盘与场景 | 结果 |
|---|---|
| 中文拼音26键，普通小浮窗 | 两轮输入、候选提交、收起和重新打开通过；实际提交“合理”等中文 |
| 中文9键，普通小浮窗 | 两轮通过，输入区/发送按钮位于原生键盘物理边界之上 |
| 中文9键，拖到屏幕下方的小窗 | 两轮通过，开键盘时避让，关闭后恢复用户拖动位置 |
| 中文9键，展开窗口 | 两轮通过，窗口高度随实际可见区域夹取并恢复 |
| 中文9键，身份背景长文本框 | 两轮通过，真实输入/提交、可达性及关闭恢复通过 |
| 数字行加26字母（36键），低位小窗 | 两轮通过；键盘物理高度由833增至946px，仍未遮挡输入和发送 |

以上六场景共12轮，使用 ADB 原生触摸，未向 textarea 注入测试文本。脚本等待输入法窗口实际 HAS_DRAWN、等待真实候选提交，通过 Android 系统独立报告的 IME 窗口物理边界校验，并用 Android 原生截图保存现场。另录制两轮九宫格低位窗口操作的20秒原生 screenrecord，作为版本附件。

实际更新前后的会话与身份设置保留。未向主故事发送测试消息；模型和搜索没有真实付费调用。

## 辅助回归

- 26项 Node 逻辑测试全部通过，包括基准窗口尺寸保持、键盘夹取后恢复、独立上下文、每轮身份指令、统计、工具循环和资料隔离。
- 浏览器普通界面回归通过：320/390/768像素、复制、停止、接续、统计与持久化。其模拟键盘仅是辅助，不代替上面的真实安卓测试。
- 两次真实 smart HTTP Git 浅克隆通过；真实安卓应用内 Gitoxide 插件安装与更新也已实际成功执行。

## 可回查证据与复现

原生脚本为 `tests/android-ime.mjs`。需要独立的 storyworkshop_ AVD、原应用、已安装插件、真实 Gboard及 ADB_PATH/ANDROID_SERIAL，详见 tests/README.md。配置是1080×2340、DPI440、Gboard正常高度，不是任意手机的通用自动化。

原始旧版失败报告与六组通过报告保存在本地隔离实验目录，不公开设备日志或内部路径。公开附件为 `android23-ime-1.0.2.mp4` 和 `android23-36key-1.0.2.png`，只含默认样例故事和测试文字。

## 结论与限度

1.0.2 在上述真实 Android 运行时与正式 APK 中通过键盘联动回归，可交付。这里的 Android 设备是隔离模拟器，不宣称已经在用户具体手机、其他 Android 版本和所有第三方输入法上通过；真实付费 API、私人长篇故事与其他版本兼容性仍保持原先的试用范围。

公开源码与发布包不包含用户故事、密钥、内部任务记录或模拟器数据。
